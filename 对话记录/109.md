# Streamline 移动短管段水流效果

日期：2026-05-26

## 本次主题

尝试 Streamline 方案二：用连续移动短管段替代离散粒子小球，让流动效果看起来更像没有间隔的水流。

## 本次修改

- 将原来的 `vtkSphereSource + vtkGlyph3DMapper` 粒子小球动画替换为动态 `vtkPolyData` 线段。
- 每一帧根据流线路径生成一段连续短线，再通过 `vtkTubeFilter` 变成白色短管段。
- 短管段沿每条 Streamline 从入口方向向出口方向移动。
- 保持现有播放按钮逻辑，仍通过“播放动画”启动。
- 保持最大流线路径数为 360。

## 验证

- 已执行 `python3 -m compileall src/foamdesk/ui/main_window_results_logic.py src/foamdesk/ui/visualization_widgets.py`。
- 已执行 `git diff --check`。
- 已执行 `PYTHONPATH=src python3 -c 'from foamdesk.ui.visualization_widgets import NativeVtkViewerDialog; print(NativeVtkViewerDialog.__name__)'`。

## 仍需人工验证

- 选择 `U` + `Streamline 流线` 并点击“加载显示”。
- 点击“播放动画”，确认白色短管段沿流线连续移动。
- 检查短管段是否比离散小球更像连续水流。
