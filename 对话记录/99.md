# 3D 预览迁移到原生 VTK

日期：2026-05-26

## 主题

将 FoamDesk 中仍使用 matplotlib 3D 的预览入口迁移到原生 VTK，保留 matplotlib 作为 2D 曲线/报告图使用。

## 本次修改

- 新增 `NativeVtkPreviewWidget`，作为通用嵌入式 VTK 预览画布。
- 将 STL 预览窗口从 matplotlib 3D 改为 VTK：
  - `VtkViewerDialog.plot_stl_file()` 使用 `vtkSTLReader` + `vtkPolyDataMapper` + `vtkActor`。
  - PNG 导出改用 `vtkWindowToImageFilter` + `vtkPNGWriter`。
- 将 STL 导入/编辑位置弹窗中的 3D 预览改为 VTK。
- 将计算域/STL 放大预览窗口改为 VTK。
- 将“绘制几何”的内嵌预览和放大预览改为 VTK：
  - 面片使用 VTK polygon。
  - 边线使用 VTK polyline。
  - 顶点编号、inlet/outlet 使用 VTK 3D text actor。
- 删除旧的 matplotlib 3D 计算域辅助函数。

## 保留内容

- 2D 残差曲线继续使用 matplotlib。
- 2D 报告图继续使用 matplotlib。
- 结果云图、切片、等值面、矢量箭头、流线继续使用原生 VTK 结果窗口。

## 验证

- 已执行 `python3 -m compileall src/foamdesk`，通过。
- 已执行 `git diff --check`，通过。
- 已搜索 `projection="3d"`、`Poly3DCollection`、`add_collection3d`、matplotlib `plot_surface()`，主代码中不再存在旧 3D matplotlib 绘制入口。
