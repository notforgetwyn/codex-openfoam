# Streamline 粒子按速度场推进

日期：2026-05-26

## 本次主题

把 Native VTK Streamline 粒子动画从统一相位播放，改成按流线上的局部速度 `|U|` 推进。

## 本次修改

- 为每条流线提取路径点和对应 `U_mag` 速度值。
- 每个粒子保存自己的 `distance` 和 `active` 状态。
- 每帧根据粒子当前位置插值得到局部速度 `|U|`。
- 粒子每帧前进距离改为 `speed * time_step`。
- 当粒子当前位置速度接近 0 时，粒子自动隐藏。
- 当粒子走到流线末端时，粒子自动隐藏。
- 当所有粒子都隐藏或到达末端后，动画统一从入口重新开始。
- 删除旧的统一 `phase` 路径采样函数。
