# Streamline 加载闪退稳定性处理

日期：2026-05-26

## 本次主题

针对“加载 Streamline 就闪退，其他显示模式正常”的问题，降低 Streamline 首次加载时的 VTK 几何压力。

## 本次修改

- 移除加载时不可见的静态 Streamline tube 管线。
- 保留 Streamline 路径数据，用于后续播放白色短管段动画。
- 默认入口种子点从高密度调整为 `18 x 9`。
- 种子点上限调整为 `32 x 20`。
- 可视化路径上限从 `360` 降为 `180`。

## 原因判断

- 当前闪退发生在加载 Streamline 阶段，不是播放动画阶段。
- 其他模式正常，说明问题集中在 Streamline 首次生成/渲染的 VTK 对象。
- 之前即使静态 tube 透明度为 0，VTK 仍然会创建 tube/filter/mapper/actor，仍会占用渲染管线。

## 验证

- 已执行 `python3 -m compileall src/foamdesk/ui/main_window_results_logic.py src/foamdesk/ui/visualization_widgets.py`。
- 已执行 `git diff --check`。

## 仍需人工验证

- 使用 `./run.sh` 启动。
- 选择 `U` + `Streamline 流线`，点击“加载显示”。
- 确认加载阶段不再闪退。
- 再点击“播放动画”，确认白色短管段能沿流线移动。
