# Native VTK Streamline 流线可视化增强

日期：2026-05-26

## 本次主题

优化 FoamDesk 结果后处理中的 Native VTK Streamline 流线显示效果。

## 本次修改

- Streamline 生成明确使用速度矢量场 `U`，不使用 `mag(U)` 做积分。
- 新增 OpenFOAM VTK 原始 case 输出读取入口，用于流线积分尽量基于体数据，而不是只基于表面 `polyData`。
- 流线种子点改为入口附近截面上的均匀采样点，支持横向和纵向分辨率配置，并保留边界 margin。
- StreamTracer 改用 `vtkRungeKutta45`，并设置传播长度、积分步长和误差参数。
- 流线输出新增 `U_mag` 标量数组，用 `|U|` 做颜色映射。
- 显示端使用 `vtkTubeFilter` 把流线加粗为管状线，tube 半径根据模型包围盒自动计算。
- Streamline 标题改为“由 U 生成，按 |U| 着色”。
- Streamline 仅允许字段 `U` 使用；如果选择 `p`、`T`、`k` 等标量字段，显示方式下拉框不再给出 Streamline。
- INLET / OUTLET 标注改为贴近计算域边界的 3D 标签。
- Streamline 视图相机放大，减少留白。

## 验证

- 已执行 `python3 -m compileall src/foamdesk`。
- 已执行 `git diff --check`。
- 已执行 `PYTHONPATH=src python3 -c 'from foamdesk.ui.main_window import MainWindow; from foamdesk.ui.visualization_widgets import NativeVtkViewerDialog; print(MainWindow.__name__, NativeVtkViewerDialog.__name__)'`。

## 仍需人工验证

- 打开带 STL 的 OpenFOAM case，选择 `U` + `Streamline 流线`，点击“加载显示”。
- 检查流线是否从 INLET 附近进入、是否按 `|U|` 彩色显示、是否能看到计算域边框和内部 STL。
