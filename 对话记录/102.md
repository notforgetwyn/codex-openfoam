# 删除 Vector/Glyph/Volume 结果显示模式

日期：2026-05-26

## 主题

从结果可视化中删除 `Vector 矢量箭头`、`Glyph 箭头`、`Volume rendering 体渲染` 三个显示模式及对应逻辑。

- `RESULT_DISPLAY_MODES` 删除：
  - `Vector 矢量箭头`
  - `Glyph 箭头`
  - `Volume rendering 体渲染`

  - `mode.startswith("Glyph")`
- 删除 VTK 箭头渲染函数：
  - `NativeVtkViewerDialog.plot_vectors()`
- 删除报告导出服务里的速度矢量箭头说明。
- 更新结果页说明文字，只保留当前接入的：
  - `Surface`
  - `Slice`
  - `Contour`
  - `Iso-surface`
  - `Streamline`
