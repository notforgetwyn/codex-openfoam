# WSL 下 PySide6/Qt xcb 插件启动失败记录

日期：2026-05-26

## 问题现象

在 WSL 中运行 FoamDesk：

```bash
./run.sh
```

程序启动失败，终端出现：

```text
qt.qpa.plugin: From 6.5.0, xcb-cursor0 or libxcb-cursor0 is needed to load the Qt xcb platform plugin.
qt.qpa.plugin: Could not load the Qt platform plugin "xcb" in "" even though it was found.
This application failed to start because no Qt platform plugin could be initialized.
```

## 原因

项目为了降低 WSL + PySide6 + 原生 VTK 窗口组合下的闪退风险，在 WSL 图形环境中优先设置：

```python
QT_QPA_PLATFORM=xcb
```

Qt 能找到 `xcb` 平台插件，但当前 WSL Ubuntu 系统缺少 Qt 6.5 之后加载该插件需要的系统依赖 `libxcb-cursor0`，所以 Qt 平台插件初始化失败，应用直接中止。

## 解决命令

在 WSL Ubuntu 中安装缺失依赖：

```bash
sudo apt update
sudo apt install -y libxcb-cursor0
```

如果后续还有其他 `xcb` 相关依赖缺失，可继续补充：

```bash
sudo apt install -y libxcb-cursor0 libxcb-xinerama0 libxcb-keysyms1 libxcb-image0 libxcb-render-util0 libxcb-icccm4
```

## 验证结果

安装 `libxcb-cursor0` 后，重新运行 FoamDesk，界面可以正常展示。

## 结论

这不是 Python 业务代码语法问题，而是 WSL 图形环境缺少 Qt `xcb` 平台插件运行依赖。后续如果在新 WSL 环境部署 FoamDesk，应把 `libxcb-cursor0` 加入环境安装说明或启动诊断提示。
