# Streamline 轨道弱化和入口粒子发射

日期：2026-05-26

## 本次主题

调整 Streamline 显示方式：不再显示醒目的黄色/红色流线，只保留低调轨道供粒子运动；粒子只能从入口端开始沿流线移动。

## 本次修改

- Streamline 静态 tube 不再使用 `|U|` 色表上色。
- 流线轨道改为固定浅灰蓝色，并降低透明度，只作为粒子运动路径参考。
- 保留 `|U| (m/s)` 色标，后续可继续用于粒子或结果范围参考。
- 粒子动画不再对不同流线设置错相位。
- 每次播放时，每条流线上的粒子都从该流线起点出发，沿路径向出口移动。
- 避免“半路突然生成粒子”的视觉效果。

## 验证

- 已执行 `python3 -m compileall src/foamdesk`。
- 已执行 `git diff --check`。
- 已执行 `PYTHONPATH=src python3 -c 'from foamdesk.ui.visualization_widgets import NativeVtkViewerDialog; print(NativeVtkViewerDialog.__name__)'`。

## 仍需人工验证

- 打开结果页，选择 `U` + `Streamline 流线`。
- 点击“加载显示”，确认不再有醒目的黄色/红色静态线。
- 点击“播放动画”，确认粒子从入口端出发，而不是从半路生成。
