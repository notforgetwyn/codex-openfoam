# Streamline 流线粗细和方向箭头优化

日期：2026-05-26

## 本次主题

根据实际截图继续优化 Native VTK Streamline 显示：流线要清楚、有颜色、有厚度，同时在连续流线路径上显示方向箭头。

## 本次修改

- 将流线管半径从按计算域最长边计算，改为按截面有效尺寸计算，并增加上下限，避免细长风洞中的 tube 过粗。
- `vtkTubeFilter` 的边数调整为 8，保留可见厚度但减少视觉拥挤。
- Streamline 种子点默认从 `16 x 8` 调整为 `12 x 6`，减少过密流线遮挡。
- 新增 `_add_streamline_direction_arrows()`：
  - 箭头来自已经由 `vtkStreamTracer` 积分得到的流线路径。
  - 只在流线路径点上抽样放少量箭头。
  - 不在每个网格点上放箭头。
  - 箭头使用 `U` 作为方向，使用 `U_mag / |U|` 进行颜色映射。
- 保持 Streamline 的语义：从入口种子点出发，沿速度矢量场 `U` 连续追踪粒子路径。

## 验证

- 已执行 `python3 -m compileall src/foamdesk`。
- 已执行 `git diff --check`。
- 已执行 `PYTHONPATH=src python3 -c 'from foamdesk.ui.visualization_widgets import NativeVtkViewerDialog; print(NativeVtkViewerDialog.__name__)'`。

## 仍需人工验证

- 打开结果页，选择 `U` + `Streamline 流线`。
- 检查流线是否比之前更细，但仍有厚度。
- 检查箭头是否贴在线上，方向是否从 INLET 指向 OUTLET。
- 检查颜色条和流线、箭头颜色是否一致。
