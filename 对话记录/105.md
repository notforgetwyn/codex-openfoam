# Streamline 粒子流动动画

日期：2026-05-26

## 本次主题

将 Streamline 的方向表达从静态箭头改为“粒子沿流线运动”的动画效果。

## 本次修改

- 移除上一版的流线方向箭头显示逻辑。
- 保留 `vtkStreamTracer` 生成的连续流线：流线仍然表示粒子从入口种子点出发，沿速度矢量场 `U` 连续追踪得到的路径。
- 在流线图加载后，复用窗口顶部“播放动画”按钮：
  - 点击“播放动画”后，粒子会沿已经生成的流线从入口向出口运动。
  - 点击“暂停动画”后，粒子停止移动。
- 粒子不是从网格点随意发射，而是基于 Streamline 的每条路径进行插值移动。
- Streamline 模式不再被时间步动画覆盖；其他结果模式仍保留原来的时间步动画逻辑。
- 粒子使用 `vtkSphereSource + vtkGlyph3DMapper` 渲染，小球沿曲线运动，表达流动方向。

## 验证

- 已执行 `python3 -m compileall src/foamdesk`。
- 已执行 `git diff --check`。
- 已执行 `python3 -m py_compile src/foamdesk/ui/visualization_widgets.py`。
- 已执行 `PYTHONPATH=src python3 -c 'from foamdesk.ui.visualization_widgets import NativeVtkViewerDialog; print(NativeVtkViewerDialog.__name__)'`。

## 仍需人工验证

- 打开结果页，选择 `U` + `Streamline 流线`。
- 点击“加载显示”后再点击 Native VTK 窗口顶部的“播放动画”。
- 检查粒子是否沿流线从 INLET 向 OUTLET 移动。
- 检查流线本体是否仍为彩色管状线，色标是否仍对应 `|U| (m/s)`。
