# 旧结果渲染函数清理

日期：2026-05-26

## 主题

删除 `main_window.py` 中已经不再作为主结果渲染路径使用的旧 matplotlib 结果绘图函数，并保留仍被实际程序调用的 STL 预览和报告导出能力。

## 本次处理

- 删除旧 `VtkViewerDialog` 中已经不用的结果渲染函数：
  - `plot_cube`
  - `plot_polydata_points`
  - `plot_field_surface`
  - `plot_pressure_surface`
  - `plot_velocity_vectors`
  - `plot_velocity_slice`
  - `plot_velocity_slice_contour`
  - `plot_velocity_contour_lines`
  - `plot_field_iso_surface`
  - `plot_velocity_streamlines`
  - `plot_pressure_points`
- 删除这些旧函数专用的辅助函数和依赖：
  - `_add_horizontal_colorbar`
  - `_scalar_mappable`
  - `_sample_points`
  - `_filter_points`
  - `_filter_points_values`
  - `_filter_faces_by_center`
  - `_filter_mask`
  - `Normalize`
  - `griddata`
- 删除旧 `VtkViewerDialog` 中已经失效的筛选、动画和刷新当前图逻辑。
- 保留仍在实际使用的旧窗口能力：
  - `plot_stl_file()`：用于 STL 预览。
  - `export_all_pngs()`：用于报告导出当前 matplotlib 预览图。
- 修正 `_update_result_field_metadata()`，不再调用已删除的 `VtkViewerDialog._scalar_values()`，统一使用 `MainWindow._scalar_values()`。
