# Streamline 动画恢复蓝色小球

日期：2026-05-26

## 本次主题

按要求将 Streamline 动画从白色短管段恢复为原来的蓝色小球粒子逻辑。

## 本次修改

- 移除短管段动画中的动态 `vtkPolyData` 线段和 `vtkTubeFilter`。
- 恢复 `vtkSphereSource + vtkGlyph3DMapper` 的蓝色小球粒子。
- 每条流线每帧显示一个蓝色小球，沿流线路径运动。
- 保留 GPU 渲染后端控制台输出逻辑。
- 保留 Streamline 加载稳定性处理：不再创建不可见静态 tube，路径上限为 180。

## 验证

- 已执行 `python3 -m compileall src/foamdesk/ui/main_window_results_logic.py src/foamdesk/ui/visualization_widgets.py`。
- 已执行 `git diff --check`。

## 仍需人工验证

- 使用 `./run.sh` 启动。
- 选择 `U` + `Streamline 流线`，点击“加载显示”。
- 点击“播放动画”，确认蓝色小球沿流线运动。
