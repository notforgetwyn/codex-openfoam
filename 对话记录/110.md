# VTK 渲染后端控制台输出

日期：2026-05-26

## 本次主题

为 FoamDesk 的 VTK 渲染窗口增加控制台输出，用于确认当前实际渲染后端是 CPU 软件渲染还是 GPU 硬件渲染。

## 本次修改

- 新增 VTK render window capabilities 解析逻辑。
- 在 VTK preview widget 和 Native VTK result viewer 首次真实 Render 后输出一次渲染后端信息。
- 输出内容包含：
  - CPU software rendering 或 GPU hardware rendering
  - OpenGL renderer
  - OpenGL vendor
  - OpenGL version

## 示例输出

```text
[FoamDesk VTK] native result viewer: GPU hardware rendering; renderer=D3D12 (NVIDIA GeForce GTX 1650); vendor=Microsoft Corporation; OpenGL=4.2 ...
```
