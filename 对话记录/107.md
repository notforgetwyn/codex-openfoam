# Streamline 连续粒子水流带

日期：2026-05-26

## 本次主题

实现 Streamline 粒子水流带：每条流线上同时显示一串粒子，让画面更接近连续流体从入口流向出口。

## 本次修改

- 保留 `vtkStreamTracer` 的流线生成逻辑，仍由入口种子点和速度矢量场 `U` 生成。
- 透明流线 tube 继续作为粒子路径，不显示黄色/红色管线。
- 每条流线每帧最多显示 16 个粒子。
- 粒子按路径相位队列排列，播放开始时从入口逐步进入。
- 粒子半径略增大，增强“水流颗粒”可见性。
- 入口种子点密度保持为 `26 x 14`，最大流线路径数保持为 360。

## 验证

- 已执行 `python3 -m compileall src/foamdesk/ui/main_window_results_logic.py src/foamdesk/ui/visualization_widgets.py`。
- 已执行 `git diff --check`。

## 仍需人工验证

- 选择 `U` + `Streamline 流线`，加载显示并点击“播放动画”。
- 检查粒子是否形成连续水流带，而不是单个点沿线移动。
- 检查入口端粒子是否逐步涌入，且不出现半路随机生成的独立粒子源。
